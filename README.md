# terminal-image

A Claude Code mod (function-hooks plugin) that shows a PNG in a pane inside the
terminal UI.

- `/img <file.png>` draws the picture with the kitty graphics protocol (real pixels).
- `/img --cells <file.png>` draws it as half-block character cells, for terminals
  without kitty graphics.

The plugin name is `terminal-image`; the folder is `claude-terminal-image`. Plugin
names starting with `claude-` are reserved and fail `claude plugin validate`, so the
two differ on purpose.

## Requirements

- Claude Code with function-hooks plugins (developed against 2.1.293).
- `node` on `PATH`: the PNG is decoded by `bin/png2cells.mjs`, which has no
  dependencies beyond Node's standard library.
- For the default (pixel) mode, a terminal that implements the kitty graphics
  protocol.

### Terminal detection and `CLAUDE_CODE_FORCE_TERMINAL_IMAGES`

Claude Code only draws images when the terminal identifies itself (XTVERSION) as
kitty >= 0.28.0 or ghostty. Other terminals that do implement kitty graphics, such as
WezTerm, fail that name check, and the pane shows the image's alt text instead.

To override the check, set the environment variable before starting Claude Code, or
in the `env` block of `~/.claude/settings.json`:

```json
{ "env": { "CLAUDE_CODE_FORCE_TERMINAL_IMAGES": "1" } }
```

This forces image output unconditionally. On a terminal without kitty graphics it
prints garbage; use `/img --cells` there instead.

Confirmed working with the override: WezTerm -> ssh -> herdr 0.9.3.

## Loading

```sh
claude --plugin-dir /path/to/claude-terminal-image
```

## Usage

```
/img [--cells] <file.png>
```

The picture is fitted into a box of at most 80x24 cells, keeping its aspect ratio.
Running `/img` again replaces the picture in the same pane.

## Auto-display

The pane also opens without typing `/img`:

- When the model reads a `.png` with the `Read` tool, that file is shown.
- The mod registers a tool, `mcp__terminal-image__show_image` (`{ path }`), which the
  model can call after it generates or saves an image. Its schema is in the prompt's
  tool list from the start (`isDeferred: false`).

Both use pixel mode. A pane opened this way, without the user asking, is only drawn
on a terminal at least 144 columns wide (110 once you have opened the pane yourself
with `/img`); on a narrower terminal it waits undrawn.

## Limits

- PNG only, 8- or 16-bit, non-interlaced. Convert other formats first, e.g.
  `magick in.jpg out.png`.
- The box size is fixed; the picture does not follow a pane resize.

## Development

Run from the mod folder:

```sh
claude plugin validate .
claude plugin test .
tsc -p .
```

`.claude-plugin/types/` and `tsconfig.json` are generated by the engine when the mod
loads.
